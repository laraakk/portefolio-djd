Exercício 2 — Galeria de Jogos

O HTML desta página já está pronto — não precisas de mexer nele. A tua tarefa é completar o ficheiro style.css para transformar a lista de cards abaixo (<div class="galeria">) numa galeria responsiva:

  • Os cards organizam-se automaticamente em colunas, lado a lado
  • Ao encolher a janela do browser, o número de colunas ajusta-se sozinho — sem escrever nenhuma media query
  • Cada card tem fundo branco, cantos arredondados e uma sombra subtil, destacando-se do fundo da página

Abre o style.css e procura os comentários /* TODO */ — é aí que tens de escrever CSS. Usa o CSS Grid (display: grid) que praticaste no guião.

💡 Se ficares preso, revê no guião "CSS Avançado" a secção 2 (CSS Grid) — a combinação repeat(auto-fit, minmax(...)) é o que resolve o TODO 2, o mais importante deste exercício.
