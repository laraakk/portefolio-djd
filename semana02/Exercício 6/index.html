📊 Painel de Estatísticas

O HTML desta página já está pronto — não precisas de mexer nele. A tua tarefa é completar o ficheiro style.css para que o painel de estatísticas (<div class="stats">) se comporte assim:

  • No telemóvel (ecrã estreito): os cards aparecem numa única coluna
  • No tablet (a partir de 640px de largura): os cards passam a 2 colunas
  • No computador (a partir de 1024px de largura): os cards passam a 3 colunas
  • O título "📊 Painel de Estatísticas" ajusta o tamanho da letra suavemente ao tamanho do ecrã — sem nenhuma media query

Ao contrário do Exercício 2 (onde o número de colunas se ajustava sozinho com auto-fit), aqui vais escrever tu os pontos de quebra (breakpoints) com @media — a técnica clássica para controlar exatamente quando o layout muda.

Abre o style.css e procura os comentários /* TODO */ — é aí que tens de escrever CSS.

💡 Se ficares preso, revê no guião "CSS Avançado" a secção 3 (Layout Responsivo) — tens lá o exemplo exato de media queries mobile-first, e a fórmula clamp() para o título.
