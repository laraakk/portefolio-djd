# Chuva de Estrelas

**Autora:** Lara Neto, nº 94093

## Objetivo

Apanhar o maior número de estrelas sem perder as 3 vidas.

## Controlos

- ← → : mover o jogador
- ESPAÇO : começar o jogo (no menu)
- R : recomeçar depois do Game Over

## Regras

- Cada estrela apanhada dá 10 pontos.
- Cada meteoro que te toca tira 1 vida; depois ficas 1 segundo invulnerável.
- A cada 5 segundos o nível sobe: os objetos caem mais depressa e com mais frequência.
- O jogo acaba quando as vidas chegam a 0.
